Where in the world is that website?

Enter any domain to find its IP address, where its server physically sits, and how long a packet takes to get there and back.

Quick trace:

How to place a long-distance packet call

1

Dial a domain

Type any website address, or tap a region button for a quick trace.

OP: ENTER DOMAIN
2

Look up the number

DNS turns the name into the server's IP address, like finding a phone number in a phonebook.

OP: DNS LOOKUP
3

Listen for the echo

A ping measures the round-trip time, and we estimate the fiber distance from it.

OP: ICMP ECHO
4

Find it on the map

The IP address is matched to a city, provider and coordinates.

OP: GEOLOCATE
