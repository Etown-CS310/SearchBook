Reference desk

Dictionary

Plain-language definitions for the domain and packet terms you will run into while using SearchBook.

A B C D F G H I L M N P R S T U W

A

A record

Domains

A DNS record that maps a domain name to an IPv4 address. It is what lets your browser turn a name into a place it can connect to.

example.com → 93.184.216.34

See also: DNS IP address Domain name

B

Bandwidth

Network basics

The maximum amount of data a connection can carry in a given amount of time, usually measured in megabits per second. It describes capacity, not delay.

See also: Latency

C

Client

Network basics

The device or program that asks for something, such as your browser requesting a web page from a server.

See also: Server

CNAME record

Domains

A DNS record that makes one name an alias of another. Looking up the alias returns the answer for the target name.

www.example.com → example.com

See also: A record DNS

D

DNS

Domains

The Domain Name System. It works like a phone book for the internet, translating domain names into IP addresses so devices can find each other.

See also: Domain name Nameserver A record

Domain name

Domains

A human-readable address for a site, such as example.com. Domain names exist so people do not have to remember numeric IP addresses.

See also: DNS Subdomain TLD

F

Firewall

Network basics

Software or hardware that allows or blocks network traffic based on rules, such as which ports or addresses may connect.

See also: Port Packet

G

Geolocation

Network basics

Estimating the physical location of an IP address using public registration data and databases. It is approximate: often accurate to a city or region, not a street.

See also: IP address

H

Header

Packets

The control information at the front of a packet. It carries details such as the source and destination addresses, the protocol, and the packet's length.

See also: Packet Payload TTL

Hop

Packets

One step a packet takes from one router to the next on its way to its destination. A trip across the internet is usually many hops.

See also: Router TTL Traceroute

HTTP / HTTPS

Network basics

The protocol browsers and web servers use to exchange pages and data. HTTPS is the same protocol wrapped in encryption, so others on the network cannot read the contents.

See also: Protocol TLS Port

I

IP address

Network basics

A numeric label that identifies a device on a network and tells packets where to go. IPv4 addresses look like 192.0.2.1; IPv6 addresses are longer and use hexadecimal.

See also: DNS Packet Geolocation

L

Latency

Packets

The time it takes for a packet to travel from one point to another, often measured as round-trip time in milliseconds. Lower is better.

See also: Bandwidth Hop Packet loss

M

MAC address

Network basics

A hardware identifier assigned to a network interface. It is used for delivery within a local network, while IP addresses handle delivery across networks.

See also: IP address Router

N

Nameserver

Domains

A server that stores DNS records for a domain and answers questions about it. A domain's registrar settings point to its authoritative nameservers.

See also: DNS Registrar

P

Packet

Packets

A small chunk of data sent over a network. Large messages, such as a web page, are split into many packets that are reassembled at the destination.

See also: Header Payload Hop

Packet loss

Packets

When one or more packets fail to arrive. It can be caused by congestion, weak signals, or faulty equipment, and it often shows up as stutter or slow loading.

See also: Packet Latency TCP

Packet sniffing

Packets

Capturing and inspecting packets as they cross a network. Network administrators use it to troubleshoot; it is also why unencrypted traffic can be read by others.

See also: Packet HTTP / HTTPS TLS

Payload

Packets

The actual data a packet carries, as opposed to the header, which describes how to deliver it.

See also: Header Packet

Port

Network basics

A number that identifies a specific service on a device, so one IP address can run many services. Web servers commonly use port 80 for HTTP and 443 for HTTPS.

See also: IP address Firewall HTTP / HTTPS

Protocol

Network basics

An agreed set of rules for how devices communicate. TCP, UDP, HTTP, and DNS are all protocols.

See also: TCP UDP HTTP / HTTPS

R

Registrar

Domains

A company accredited to sell and manage domain name registrations. You rent a domain through a registrar, usually on a yearly basis.

See also: Domain name WHOIS Nameserver

Router

Network basics

A device that forwards packets between networks, choosing the next hop on the path toward the destination.

See also: Hop Packet MAC address

S

Server

Network basics

A computer or program that provides data or services to clients, such as a web server that delivers pages.

See also: Client Port

Subdomain

Domains

A prefix added in front of a domain to create a separate section or service. In blog.example.com, blog is a subdomain of example.com.

See also: Domain name TLD

T

TCP

Packets

Transmission Control Protocol. It sets up a connection, numbers packets, and resends any that go missing, so data arrives complete and in order. Web pages and email typically use it.

See also: UDP Packet loss Protocol

TLD

Domains

Top-level domain: the last part of a domain name, such as .com, .org, .edu, or a country code like .uk.

See also: Domain name Subdomain

TLS

Network basics

Transport Layer Security. The encryption technology behind HTTPS that keeps data private and confirms you are talking to the real site.

See also: HTTP / HTTPS Packet sniffing

Traceroute

Packets

A tool that shows the path packets take to a destination by listing each hop and how long it took. It is a good way to see network paths in action.

See also: Hop TTL Latency

TTL

Packets

Time to live. In a packet header, it is a counter that drops by one at every hop; when it reaches zero the packet is discarded, which stops packets from circling forever. In DNS, TTL is how long a record may be cached.

See also: Hop Header DNS

U

UDP

Packets

User Datagram Protocol. It sends packets without setting up a connection or checking delivery, which makes it fast. Video calls, games, and DNS queries often use it.

See also: TCP Protocol Packet loss

W

WHOIS

Domains

A public lookup service that reports registration details for a domain, such as the registrar and when it was created or expires. Owner details are often hidden by privacy services.

See also: Registrar Domain name
